## Hi, I'm Mehdi 👋

I'm an Assistant Professor of Computer Science at **Tunis Business School** (University of Tunis), where I also direct the **Career Center (4C)**. I've spent more than ten years teaching programming and helping students get from the classroom into their first jobs.

I use this GitHub account for the small tools and demos I build for my courses, and for my personal website.

### 📚 What I teach

| Course | Level | Stack |
|---|---|---|
| Web Development | Bachelor | HTML, CSS, JavaScript |
| Advanced Web Development | Bachelor | React |
| Object-Oriented Programming | Bachelor | Java |

Earlier courses include distributed applications, data mining, big data, multi-agent systems and web application security.

### 🛠️ Projects here

- **[mkhouja.github.io](https://mkhouja.github.io)**: my personal website and online CV.
- **[tbs-draw-lots](https://github.com/mkhouja/tbs-draw-lots)**: a classroom tool for my Web Development course. Each pair of students clicks once to get its code snippet for the day's activity.

### 🌍 Beyond the classroom

- Member, rapporteur and coordinator of Tunisia's **National Commission of Computer Science**, which evaluates university programs.
- Coordinator of **Erasmus+** projects, including [ITG4TU](https://itg4tu.uib.eu/) (IT governance for Tunisian universities) and [HEALING](https://sites.ju.edu.jo/en/healing).
- PhD in Computer Science from the **University of the Balearic Islands**, Spain, with research on web performance and distributed services.
